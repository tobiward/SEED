# Seed

Smart Eating Every Day. A free diet tracker that installs on your phone's home screen from the browser, with no app store.

## Features

- Log foods with an amount and a measure (grams, ounces, fluid ounces, cups, servings)
- Calorie and protein rings that fill through the day
- Recipes: save a food once with per-unit calories and protein, then type only the amount
- Weight tracking and automatic protein, calorie and tracking streaks
- Weight, calorie and protein graphs by week, month and year
- Works offline
- Backup and restore your data as a JSON file

## Your data stays on your device

Everything is stored in your browser's local storage. Nothing is sent to a server. Use **User > Export backup** now and then, especially on iPhone, since browsers can clear storage for sites you do not visit.

## Install

Open the site, then:

- **Android (Chrome):** menu > Install app
- **iPhone (Safari):** Share > Add to Home Screen
- **Computer (Chrome or Edge):** install icon in the address bar
